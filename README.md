# Clinic Appointment Booking System

## About the Project
The Clinic Appointment Booking System is a web-based application designed to simplify the process of booking and managing clinic appointments.

## Features
- Patient registration
- Patient login
- Doctor details
- Appointment booking
- Payment page
- Dashboard
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Modules
- Patient Module
- Doctor Module
- Appointment Module
- Payment Module
- Dashboard

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Use the available pages to navigate through the system.
